# 2026 하천·계곡 정비 웹 프레젠테이션

## 실행
`index.html` 파일을 더블클릭하면 별도 서버 없이 실행됩니다.

## GitHub Pages 배포
1. 이 ZIP의 파일과 `assets` 폴더를 GitHub 저장소 최상위에 업로드합니다.
2. Settings → Pages → Build and deployment → Deploy from a branch를 선택합니다.
3. Branch `main`, Folder `/ (root)`를 선택해 Save합니다.
4. Pages URL을 열면 웹 프레젠테이션이 실행됩니다.

## 조작
- 상단 목차, 아래 이전/다음, 방향키, PageUp/Down, 스크롤, 모바일 스와이프
- 이미지 클릭 또는 `내용 보기` 버튼: 슬라이드 핵심 내용 보기
- `⛶` 전체 화면
- 링크 `#slide-5`처럼 특정 슬라이드 직접 열기

## 기술 및 저작물
- HTML/CSS/JavaScript 정적 웹. 외부 CDN/서버/DB 없음.
- 원본 PPTX의 9장 슬라이드를 1601×900 PNG로 렌더링해 시각적 충실도를 유지합니다.
- 글자는 화면 이미지에 포함되어 있으므로 텍스트 내용을 수정하려면 원본 PPTX를 수정한 후 해당 이미지를 교체해야 합니다.
- 접근성 및 핵심 요약은 우측 정보 패널과 이미지 대체 텍스트로 제공합니다.
- 원본 법령 안내는 현장·날짜에 따라 달라질 수 있으므로 외부 배포 전 사실관계를 확인하세요.
